## 核心概念速查

| 概念 | 说明 | 关键文件 |
|------|------|---------|
| **Provider 模式** | 屏蔽云 GPU 厂商差异的统一接口 | `src/remote/provider.py` |
| **SSHProvider** | SSH+SFTP 接入（AutoDL/Vast.ai/阿里云） | `src/remote/providers/ssh_provider.py` |
| **HTTPProvider** | HTTP API 接入（Modal/Replicate） | `src/remote/providers/http_provider.py` |
| **TTS 调度器** | 根据配置路由 TTS 到本地或云端 | `src/tts/scheduler.py` |
| **TaskQueue** |  Provider 无关的异步任务队列 | `src/remote/task_queue.py` |

## 项目结构

```
口播视频生成系统/
├── docs/                        # 开发文档
│   └── *.md                     # 本文档系统
├── src/
│   ├── tts/                     # 语音合成模块
│   │   ├── cosyvoice_tts.py     # CosyVoice 引擎封装
│   │   ├── scheduler.py         # TTS 位置调度器（本地/云端）
│   │   └── audio_utils.py       # 音频处理工具
│   ├── remote/                  # 远程推理模块
│   │   ├── provider.py          # CloudProvider 抽象基类
│   │   ├── transfer.py          # 文件传输策略抽象
│   │   ├── task_queue.py        # 异步任务队列
│   │   ├── providers/           # Provider 实现
│   │   │   ├── __init__.py
│   │   │   ├── auto_provider.py # 自动选择 Provider
│   │   │   ├── ssh_provider.py  # SSH/SFTP 实现
│   │   │   └── http_provider.py # HTTP API 实现
│   │   └── server/              # GPU 服务器端代码
│   │       ├── infer_avatar.py  # LongCat 推理脚本
│   │       ├── api_server.py    # FastAPI 服务（HTTP 模式）
│   │       └── requirements_server.txt
│   ├── preprocess/              # 预处理模块
│   │   ├── image_prep.py        # 图片裁剪/增强
│   │   └── video_prep.py        # 视频预处理
│   ├── postprocess/             # 后处理模块
│   │   ├── subtitle.py          # 字幕合成
│   │   └── compose.py           # 视频合成
│   └── pipeline.py              # 完整流水线入口
├── config/                      # 配置文件
│   ├── default.yaml             # 默认配置模板
│   ├── example_ssh.yaml         # SSH 方案示例
│   └── example_http.yaml        # HTTP 方案示例
├── scripts/                     # 辅助脚本
│   ├── setup_local.sh
│   ├── setup_cloud.sh
│   └── deploy_to_cloud.sh
└── tests/
    ├── test_tts.py
    ├── test_providers.py
    └── test_pipeline.py
```
