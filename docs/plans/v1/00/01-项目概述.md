# 01 — 项目概述

## 1.1 项目背景

口播视频（Talking Head Video）是短视频、直播、在线教育、数字人客服等领域的核心内容形式。传统的口播视频制作需要真人出镜录制，成本高、效率低、难以批量生产。

LongCat-Video-Avatar-1.5 是美团龙猫团队于 2026 年 5 月发布的开源音频驱动数字人视频生成框架，相比 v1.0 升级包括：Whisper-Large-v3 音频编码器、步数蒸馏（8 步推理）、INT8 量化、长视频稳定性、风格泛化。

## 1.2 项目目标

构建一套**通用、灵活的口播视频自动生成系统**，核心能力：

1. **图片 → 口播视频**：给定一张人物头像照片 + 文案脚本，生成人物说话视频
2. **视频 → 口播视频**：给定参考视频 + 新文案，驱动原人物说出新内容（换口型）
3. **自动化生产**：批量处理、任务队列

## 1.3 核心流程

```
[输入]                   [处理]                       [输出]
头像图片 ─→ 图片预处理 ─→ LongCat AI2V ─→ 字幕合成 ─→ 口播视频
文案脚本 ─→ TTS 合成  ─→ (图片+音频)                  (含音频)
          (本地或云端)
```

## 1.4 通用性设计

本系统在三个维度实现通用性：

### 1.4.1 云 GPU 厂商无关（Provider 模式）

```
┌───────────────┐     ┌────────────────┐     ┌──────────────────┐
│  系统上层代码   │────→│ Provider 抽象接口 │────→│ SSHProvider       │
│  (Pipeline /  │     │ upload_file()  │     │ → AutoDL/Vast.ai  │
│   TaskQueue)  │     │ download_file()│     │ → 阿里云/腾讯云    │
│               │     │ run_command()  │     ├──────────────────┤
│               │     │ check_gpu()    │────→│ HTTPProvider      │
│               │     └────────────────┘     │ → Modal/Replicate │
│                                            │ → 自建API服务      │
└────────────────────────────────────────────┴──────────────────┘
```

- 支持 **SSH + SFTP**（AutoDL, Vast.ai, 阿里云, 腾讯云, 自建服务器）
- 支持 **HTTP REST API**（Modal, Replicate, 自建 API 服务）
- 通过 `provider.type` 配置切换，代码零改动

### 1.4.2 TTS 位置灵活

- **本地执行**：Mac CPU 运行 CosyVoice，节省云资源
- **云端执行**：TTS 在云 GPU 服务器上运行，减少传输
- 通过 `tts.run_on: "local" | "cloud"` 配置切换

### 1.4.3 传输方式多样

- **SFTP**：SSH 模式的标准文件传输
- **HTTP multipart**：API 模式的标准文件传输
- 底层由 Provider 封装，上层调用透明

## 1.5 技术栈

### 系统核心

| 组件 | 技术选型 | 说明 |
|------|---------|------|
| 编程语言 | Python 3.10+ | 主开发语言 |
| 语音合成 | CosyVoice-300M-SFT | 阿里通义开源，中文效果极佳 |
| 音频处理 | librosa, soundfile, ffmpeg | 格式转换、采样率适配 |
| 远程通信 | paramiko / httpx | Provider 底层传输 |
| 任务调度 | Python asyncio | 异步任务队列 |

### 云 GPU 环境

| 组件 | 技术选型 | 说明 |
|------|---------|------|
| 推理框架 | PyTorch 2.6.0 + CUDA 12.4 | LongCat 运行环境 |
| 注意力 | FlashAttention-2.7.4 | GPU 加速 |
| 核心模型 | LongCat-Video-Avatar-1.5 | 音频驱动视频生成 |
| 可选 API 服务 | FastAPI + Uvicorn | HTTP 模式服务端 |

## 1.6 部署方案一览

| 方案 | TTS 位置 | 云接入 | 适用场景 |
|------|---------|-------|---------|
| **方案 A** | 本地 | SSH | 个人开发调试 |
| **方案 B** | 本地 | HTTP | Serverless/API |
| **方案 C** | 云端 | SSH | 全云化小团队 |
| **方案 D** | 云端 | HTTP | 微服务生产环境 |

## 1.7 限制说明

- **LongCat 推理必须 NVIDIA GPU + CUDA**，不支持 Apple Silicon MPS
- 模型大小约 16~35 GB（INT8 vs FP16）
- 推理时间：4090 单卡 5 秒 480P 视频约 2~5 分钟
- HTTP 模式需要云 GPU 部署 API 服务
