# 07 — 完整工作流

## 7.1 快速开始

### 环境准备

参见 [环境搭建指南](04-环境搭建指南.md)，根据你的场景选择方案 A~D。

### 配置

```bash
# 方案 A（本地TTS + SSH云GPU）— 开发调试首选
cp config/default.yaml config/local.yaml
vim config/local.yaml
# 填入云 GPU 连接信息和 TTS 配置
```

## 7.2 命令行使用

### 模式一：图片 → 口播视频（AI2V）

```bash
# 基本用法（自动使用配置中的 TTS 位置和 Provider）
python src/pipeline.py \
    --mode image \
    --image examples/images/portrait.jpg \
    --script scripts/test_script.txt \
    --output outputs/final/result.mp4

# 完整参数
python src/pipeline.py \
    --mode image \
    --image examples/images/portrait.jpg \
    --script scripts/test_script.txt \
    --output outputs/final/result.mp4 \
    --tts-mode sft \
    --voice default \
    --speed 1.0 \
    --resolution 480P \
    --subtitle \
    --config config/local.yaml

# 指定不同的 TTS 位置（覆盖配置文件）
python src/pipeline.py \
    --mode image \
    --image examples/images/portrait.jpg \
    --script scripts/test_script.txt \
    --output outputs/final/result.mp4 \
    --tts-run-on cloud  # 强制在云端执行 TTS
```

### 模式二：视频 → 口播视频（换口型）

```bash
# 用新文案驱动已有视频中的人物说话
python src/pipeline.py \
    --mode video \
    --video examples/videos/reference.mp4 \
    --script scripts/new_script.txt \
    --output outputs/final/result.mp4
```

### 模式三：批量处理

```bash
# 批量处理多个文案
python src/pipeline.py \
    --mode batch \
    --image examples/images/portrait.jpg \
    --script-dir scripts/batch/ \
    --output-dir outputs/batch/
```

## 7.3 Python API 使用

```python
from src.pipeline import LipSyncPipeline

# 初始化流水线（从配置创建 Provider 和 TTS）
pipeline = LipSyncPipeline(config_path='config/local.yaml')

# 图片 → 口播视频
result = pipeline.image_to_video(
    image_path='examples/images/portrait.jpg',
    script="大家好，欢迎来到我的频道。",
    output_path='outputs/final/result.mp4',
    tts_kwargs={'speed': 1.0, 'voice': 'default'},
    subtitle=True
)

print(f"视频已生成: {result['video_path']}")

# 视频换口型
result = pipeline.video_to_video(
    video_path='examples/videos/reference.mp4',
    script="这是一个全新的口播内容。",
    output_path='outputs/final/lip_sync_result.mp4'
)

# 批量处理
results = pipeline.batch_process(
    image_path='examples/images/portrait.jpg',
    scripts=["文案一", "文案二", "文案三"],
    output_dir='outputs/batch/'
)
```

## 7.4 工作流步骤详解

### 通用流程（Provider 和 TTS 位置无关）

```
输入验证 → TTS合成 → 文件上传 → 远程推理 → 文件下载 → 后处理 → 输出
```

### 各方案的具体数据流

#### 方案 A（本地TTS + SSH 云 GPU）

```
[本地]
  图片预处理 ⟶ TTS合成（CosyVoice on CPU）
                                │
                           SFTP 上传（图片 + 音频）
                                │
[云 GPU]                        ▼
                          LongCat 推理
                                │
                           SFTP 下载（视频）
                                │
[本地]                          ▼
                          字幕合成 → 最终编码 → result.mp4
```

#### 方案 B（本地TTS + HTTP API）

```
[本地]
  图片预处理 ⟶ TTS合成（CosyVoice on CPU）
                                │
                      HTTP POST /infer（multipart: 图片+音频）
                                │
[云 GPU]                        ▼
                      FastAPI 服务 → LongCat 推理
                                │
                      HTTP GET /download（视频文件）
                                │
[本地]                          ▼
                          字幕合成 → 最终编码 → result.mp4
```

#### 方案 C（云端TTS + SSH 云 GPU）

```
[本地]
  图片预处理
       │
  SFTP 上传（图片 + 文案文本）
       │
[云 GPU]  
       ▼
  TTS合成（CosyVoice on Cloud）→ LongCat 推理
       │
  SFTP 下载（视频）
       │
[本地]  ▼
  字幕合成 → 最终编码 → result.mp4
```

#### 方案 D（云端TTS + HTTP API）

```
[本地]
  图片预处理
       │
  HTTP POST /infer（multipart: 图片+文案文本）
       │
[云 GPU]
       ▼
  FastAPI 服务 → TTS合成 → LongCat 推理
       │
  HTTP GET /download（视频文件）
       │
[本地]  ▼
  字幕合成 → 最终编码 → result.mp4
```

## 7.5 运行时配置覆盖

大部分配置可在运行时通过参数覆盖：

```bash
# 覆盖 TTS 位置
python src/pipeline.py ... --tts-run-on local
python src/pipeline.py ... --tts-run-on cloud

# 覆盖 Provider 类型
python src/pipeline.py ... --provider-type ssh
python src/pipeline.py ... --provider-type http

# 覆盖推理参数
python src/pipeline.py ... --resolution 720P --use-distill
```

## 7.6 配置参考

完整的通用配置模板：

```yaml
# config/default.yaml
project:
  name: "口播视频生成系统"
  version: "1.0.0"

# ─── TTS 配置 ──────────────────────────────────
tts:
  engine: "cosyvoice"
  run_on: "local"              # "local" | "cloud" — TTS 执行位置
  model_dir: "pretrained_models/CosyVoice-300M-SFT"
  device: "cpu"                # TTS 在本地时使用
  default_speed: 1.0
  default_voice: "default"
  target_sample_rate: 16000

# ─── 云 GPU Provider 配置 ──────────────────────
provider:
  type: "ssh"                  # "ssh" | "http"
  
  # SSH 模式（方案 A/C）
  ssh:
    host: "your-instance-ip"
    port: 22
    username: "root"
    key_filename: "~/.ssh/cloud_gpu"
    remote_work_dir: "/root/lip-sync"
    remote_weights_dir: "/root/weights/LongCat-Video-Avatar-1.5"
    remote_inputs_dir: "/root/lip-sync/inputs"
    remote_outputs_dir: "/root/lip-sync/outputs"
    timeout_seconds: 30        # SSH 连接超时
  
  # HTTP 模式（方案 B/D）
  http:
    api_base_url: "https://api.example.com/lip-sync"
    api_key: ""
    timeout_seconds: 1800      # 推理超时 30 分钟

# ─── LongCat 推理参数 ──────────────────────────
inference:
  nproc_per_node: 1
  context_parallel_size: 1
  model_type: "avatar-v1.5"
  use_distill: true
  use_int8: true
  resolution: "480P"           # "480P" | "720P"
  num_segments: 1              # 视频延续段数
  ref_img_index: 10
  mask_frame_range: 3
  audio_cfg: 3.0

# ─── 后处理 ────────────────────────────────────
postprocess:
  add_subtitle: true
  subtitle_font: "Noto Sans SC"
  subtitle_font_size: 48
  output_codec: "h264"
  output_bitrate: "8M"
```
