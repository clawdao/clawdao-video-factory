# 06 — 远程推理模块

## 6.1 概述

远程推理模块采用 **Provider 抽象层** 设计，屏蔽不同云 GPU 厂商和通信方式的差异，提供统一的推理接口。

```
┌──────────────────────────────────────────────────┐
│                  远程推理模块                      │
│                                                    │
│  ┌──────────────┐   ┌──────────────────────────┐  │
│  │  TaskQueue    │   │  Provider 抽象接口        │  │
│  │  (任务调度)   │──►│  - upload_file()          │  │
│  │  状态管理     │   │  - download_file()        │  │
│  │  重试机制     │   │  - run_command()          │  │
│  └──────────────┘   │  - check_gpu()            │  │
│                      └───────────┬──────────────┘  │
│                                  │                  │
│                     ┌────────────┴────────────┐    │
│                     │                         │    │
│               ┌─────┴─────┐           ┌──────┴───┐│
│               │SSHProvider │           │HTTPProv. ││
│               │(SFTP传输)  │           │(REST API)││
│               └─────┬─────┘           └──────┬───┘│
└─────────────────────┼───────────────────────┼────┘
                      │                       │
              ┌───────┴───────┐       ┌───────┴───────┐
              │ AutoDL /       │       │ Modal /       │
              │ Vast.ai /      │       │ Replicate /   │
              │ 阿里云 / 腾讯云  │       │ 自建 API 服务  │
              └───────────────┘       └───────────────┘
```

## 6.2 Provider 抽象接口

```python
# src/remote/provider.py
from abc import ABC, abstractmethod
from dataclasses import dataclass

@dataclass
class GPUInfo:
    """GPU 信息"""
    index: int
    name: str
    memory_total_gb: float
    memory_free_gb: float
    memory_used_gb: float

@dataclass
class CommandResult:
    """命令执行结果"""
    stdout: str
    stderr: str
    return_code: int
    success: bool

class CloudProvider(ABC):
    """云 GPU 提供商抽象基类"""
    
    @abstractmethod
    def upload_file(self, local_path: str, remote_path: str) -> bool:
        """上传文件到云端"""
    
    @abstractmethod
    def download_file(self, remote_path: str, local_path: str) -> bool:
        """从云端下载文件"""
    
    @abstractmethod
    def run_command(self, command: str, workdir: str | None = None,
                    timeout: int | None = None) -> CommandResult:
        """在云端执行命令"""
    
    @abstractmethod
    def check_gpu(self) -> list[GPUInfo]:
        """获取 GPU 列表及状态"""
    
    @abstractmethod
    def file_exists(self, remote_path: str) -> bool:
        """检查远程文件是否存在"""
    
    @abstractmethod
    def close(self):
        """关闭连接"""
```

## 6.3 内置 Provider 实现

### SSHProvider

基于 paramiko 的 SSH + SFTP 实现，适用于任何提供 SSH 访问的云 GPU。

```python
# src/remote/providers/ssh_provider.py
class SSHProvider(CloudProvider):
    """
    SSH/SFTP 方式连接云 GPU
    
    适用厂商：AutoDL, Vast.ai, 阿里云, 腾讯云, 自建服务器
    传输方式：SFTP（基于 SSH 的文件传输协议）
    """
    
    def __init__(self, host: str, port: int = 22, username: str = 'root',
                 key_filename: str | None = None, password: str | None = None,
                 timeout: int = 30):
        ...
```

**配置示例：**

```yaml
provider:
  type: "ssh"
  host: "your-instance-ip"
  port: 12345
  username: "root"
  key_filename: "~/.ssh/cloud_gpu"
  # 或使用密码（不推荐）
  # password: ""
  timeout: 30
  # 远程工作目录
  remote_work_dir: "/root/lip-sync"
  remote_weights_dir: "/root/weights/LongCat-Video-Avatar-1.5"
```

### HTTPProvider

基于 HTTP/HTTPS 的 REST API 实现，适用于部署了推理 API 的场景。

```python
# src/remote/providers/http_provider.py
class HTTPProvider(CloudProvider):
    """
    HTTP API 方式连接云 GPU
    
    适用场景：Modal, Replicate, 自建推理 API 服务
    传输方式：HTTP multipart upload / download
    """
    
    def __init__(self, api_base_url: str, api_key: str | None = None,
                 timeout: int = 1800):
        ...
```

**配置示例：**

```yaml
provider:
  type: "http"
  api_base_url: "https://api.modal.com/lip-sync"
  api_key: "sk-xxxxxxxxxxxxxxxx"
  timeout: 1800  # 推理超时 30 分钟
```

**HTTP API 端点约定（服务器端需实现）：**

| 端点 | 方法 | 说明 |
|------|------|------|
| `/upload` | POST | 上传输入文件（multipart/form-data） |
| `/infer` | POST | 触发推理任务，返回 task_id |
| `/status/{task_id}` | GET | 查询推理状态 |
| `/download/{task_id}` | GET | 下载推理结果 |
| `/cancel/{task_id}` | POST | 取消推理任务 |
| `/gpu` | GET | 查询 GPU 状态 |

### AutoProvider（自动选择）

```python
# src/remote/providers/auto_provider.py
class AutoProvider:
    """根据配置自动选择/创建合适的 Provider"""
    
    @staticmethod
    def create(config: dict) -> CloudProvider:
        provider_type = config.get('type', 'ssh')
        if provider_type == 'ssh':
            from .ssh_provider import SSHProvider
            return SSHProvider(**config['ssh'])
        elif provider_type == 'http':
            from .http_provider import HTTPProvider
            return HTTPProvider(**config['http'])
        else:
            raise ValueError(f"Unknown provider type: {provider_type}")
```

### 用法示例

```python
# 方式 1: 通过 AutoProvider 自动创建
from src.remote.providers import AutoProvider

provider = AutoProvider.create({
    'type': 'ssh',
    'host': 'xxx',
    'port': 22,
    'username': 'root',
    'key_filename': '~/.ssh/id_rsa'
})

# 方式 2: 直接创建特定 Provider
from src.remote.providers.ssh_provider import SSHProvider
provider = SSHProvider(host='xxx', port=22, ...)

# 统一调用
result = provider.upload_file('local/img.jpg', '/remote/img.jpg')
gpu_info = provider.check_gpu()
cmd_result = provider.run_command('nvidia-smi')
```

## 6.4 任务队列

TaskQueue 使用 Provider 接口，与具体传输方式解耦：

```python
from src.remote.task_queue import TaskQueue

# 传入 Provider，不关心是 SSH 还是 HTTP
queue = TaskQueue(
    provider=provider,  # CloudProvider 实例
    inference_config={...},
    max_concurrent=1,
    retry_limit=3,
    timeout_minutes=30
)

# 添加任务
task_id = queue.add_task(
    mode='ai2v',
    image='inputs/person.jpg',
    audio='inputs/audio.wav',
    text="一个年轻女性正在微笑说话",
    output_name='result.mp4'
)
```

## 6.5 服务器端组件

### 推理脚本（SSH 模式）

    --mode ai2v \
    --image /root/inputs/image.jpg \

## 6.7 错误处理

| 错误 | 可能原因 | 处理方式 |
|------|---------|---------|
| `ProviderConnectionError` | SSH 连接失败 / API 不可达 | 重试 3 次，检查网络和凭据 |
| `FileTransferError` | 上传/下载中断 | 校验 MD5，断点续传 |
| `GPUNotAvailableError` | 无 GPU 或显存不足 | 自动降级分辨率到 480P |
| `InferenceTimeoutError` | 推理超时 | 可配置超时时间，默认 30 分钟 |
| `ModelLoadError` | 模型文件损坏或缺失 | 检查模型路径和文件完整性 |
| `ProviderNotSupportedError` | 不支持的 provider type | 检查 `provider.type` 配置值 |
