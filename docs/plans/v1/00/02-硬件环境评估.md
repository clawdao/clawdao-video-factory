# 02 — 硬件环境评估

## 2.1 本机硬件信息

| 项目 | 值 |
|------|------|
| 型号 | Mac (Apple M4 Pro) |
| CPU | 10 核 (4 性能 + 6 能效) |
| 内存 | 64 GB |
| 磁盘 | 3.6 TB |
| GPU | Apple M4 Pro 集成 GPU（无 NVIDIA GPU） |
| CUDA | 不支持 |
| 操作系统 | macOS 26.5.2 |
| Python | 3.14.6 |
| Conda | 25.1.1 |

**结论：LongCat 推理（需要 NVIDIA GPU）不能在本机运行，但其他模块可以。详见下方各模块硬件需求。**

## 2.2 各模块硬件需求

### LongCat-Video-Avatar-1.5 推理

| 项目 | 要求 |
|------|------|
| GPU | **必须** NVIDIA GPU，支持 CUDA |
| 显存 | ≥ 16 GB（INT8 量化），推荐 24 GB |
| CUDA | 12.4（推荐） |
| Python | 3.10 |

**显存详细估算：**

| 模型组件 | FP16 大小 | INT8 大小 |
|---------|-----------|-----------|
| DiT Base Model (6 个分片) | ~30 GB | ~16 GB (4 分片) |
| DMD LoRA | ~2.5 GB | ~2.5 GB |
| Whisper-Large-v3 | ~3 GB (FP32) | ~3 GB |
| **模型总计** | **~35 GB** | **~21 GB** |

**推理显存需求（含中间激活）：**

| 配置 | 单卡显存需求 | 推荐 GPU 配置 |
|------|------------|--------------|
| FP16 × 2 GPUs | ~20 GB/卡 | 2× RTX 4090 (24GB) |
| INT8 × 2 GPUs | ~14 GB/卡 | 2× RTX 4090 (24GB) ✅ |
| INT8 × 1 GPU | ~24 GB | 1× RTX 4090 (24GB) ⚠️ 紧张 |
| INT8 × 1 GPU (480P) | ~20 GB | 1× RTX 4090 (24GB) ✅ 推荐 |

### CosyVoice TTS

| 部署位置 | 硬件要求 | 说明 |
|---------|---------|------|
| **本地 CPU**（推荐） | 无需 GPU，M4 Pro 64GB 充裕 | 1 秒语音约需 0.5~1 秒 CPU 时间 |
| **本地 GPU** | MPS / CUDA 均可 | M4 Pro MPS 可用，加速不明显 |
| **云端 CPU** | 云 GPU 服务器的 CPU 核心 | 与 LongCat 同机，省去音频传输 |
| **云端 GPU** | TTS 也可利用 GPU | 加速效果有限，GPU 留给 LongCat 更优 |

### 图片/视频预处理

- **硬件**：CPU + 内存，本机 M4 Pro 64GB 完全胜任
- **依赖**：OpenCV, PIL, FFmpeg

### 后处理（字幕合成等）

- **硬件**：CPU 即可，本机完全胜任
- **依赖**：FFmpeg

## 2.3 综合结论

| 模块 | 能否在本机运行 | 运行位置 | 原因 |
|------|-------------|---------|------|
| TTS 配音 | ✅ 是 | 本地 Mac CPU | CosyVoice 可在 CPU 运行 |
| 图片/视频预处理 | ✅ 是 | 本地 Mac | 轻量 CPU 任务 |
| 字幕生成 | ✅ 是 | 本地 Mac | 文本处理 |
| **LongCat 推理** | **❌ 否** | **云 GPU** | **必须 NVIDIA GPU + CUDA** |
| 视频后处理 | ✅ 是 | 本地或云端均可 | FFmpeg 通用 |

## 2.4 推荐的云 GPU 提供商

LongCat 推理需要云 GPU，系统已通过 **Provider 抽象层** 屏蔽了厂商差异，以下厂商均可：

| 厂商 | 特点 | 推荐 GPU | 价格参考 | 接入方式 |
|------|------|---------|---------|---------|
| **AutoDL** | 国内主流，按量计费，PyTorch 镜像完善 | RTX 4090 | ¥2~4/小时 | SSH |
| **Vast.ai** | 全球节点，价格透明 | RTX 4090 | $0.3~0.5/小时 | SSH |
| **阿里云/腾讯云** | 企业级，稳定可靠 | V100/A10/4090 | ¥5~20/小时 | SSH |
| **Modal** | Serverless，按调用付费 | A100 | ~$0.05/次 | HTTP API |
| **Replicate** | 托管推理，零运维 | A100 | ~$0.05/次 | HTTP API |
| **自建服务器** | 自有 GPU，长期使用 | 按需 | 一次性投入 | SSH |
