本项目的测试分为以下层次：

| 层级 | 测试类型 | 范围 | 执行频率 |
|------|---------|------|---------|
| L0 | 单元测试 | 核心函数逻辑 | 每次提交 |

| L2 | 端到端测试 | 完整流水线 | 每次发布 |
| L3 | 效果评估 | 视觉/听觉质量 | 按需 |

## 10.4 效果评估标准

### 客观指标

| 指标 | 测量方法 | 目标值 |
|------|---------|--------|
| 唇音同步误差 (LSE) | SyncNet 评估 | LSE-D < 7.0 |
| 画面清晰度 | PSNR / SSIM | 与原图对比 |
| 时序一致性 | Warping Error | 越低越好 |
| 生成速度 | 每秒帧数 (fps) | > 0.5 fps |
| 音频对齐 | 音频时间戳偏差 | < 100ms |

### 主观评分 (MOS)

| 维度 | 评分标准 | 目标 MOS |
|------|---------|---------|
| 唇形同步 | 1~5 分，5 分为完全同步 | ≥ 4.0 |
| 画面自然度 | 1~5 分，5 分为真人级别 | ≥ 3.5 |
| 动作自然度 | 1~5 分 | ≥ 3.5 |
| 音频质量 | 1~5 分 | ≥ 4.0 |
| 整体观感 | 1~5 分 | ≥ 3.5 |

## 10.6 验收标准

以下条件满足后可认为系统达到可用状态：

- [ ] 图片 → 口播视频：单次运行成功率 > 90%
- [ ] 视频换口型：唇形同步达到基本可用水平
- [ ] 批量处理：连续 100 条任务无中断
- [ ] 单条视频生成时间（含排队）< 10 分钟
- [ ] MOS 主观评分 > 3.5
- [ ] 云 GPU 费用可控（单条 < ¥0.5）
