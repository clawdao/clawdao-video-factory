# 09 — 部署与运维

## 9.1 云 GPU 服务器管理

### 9.1.1 AutoDL 实例生命周期

| 操作 | 说明 | 注意 |
|------|------|------|
| 创建实例 | 选择 GPU 型号和镜像 | 推荐 RTX 4090 + PyTorch 2.6 |
| 开机 | 启动实例开始计费 | 按秒计费 |
| 关机 | 停止计费，保留数据 | 数据盘文件保留 |
| 保存镜像 | 将环境保存为自定义镜像 | 下次可直接使用 |
| 销毁 | 删除实例和数据 | **数据不可恢复** |

**省钱建议**：
- 不使用实例时及时关机
- 批量处理时集中开机处理
- 使用数据盘存储模型（关机不丢失）

### 9.1.2 初始化脚本

一键初始化云 GPU 环境：

```bash
# scripts/setup_cloud.sh
#!/bin/bash
set -e

echo "=== 创建目录结构 ==="
mkdir -p /root/lip-sync/{inputs,outputs,server}
mkdir -p /root/autodl-tmp/weights

echo "=== 克隆 LongCat-Video ==="
git clone --single-branch --branch main \
    https://github.com/meituan-longcat/LongCat-Video.git \
    /root/lip-sync/LongCat-Video

echo "=== 安装依赖 ==="
# 假设 conda 环境 already activated
pip install flash_attn==2.7.4.post1
conda install -c conda-forge librosa ffmpeg -y
pip install -r /root/lip-sync/LongCat-Video/requirements_avatar.txt
pip install pyyaml tqdm opencv-python pillow

echo "=== 下载模型 ==="
huggingface-cli download meituan-longcat/LongCat-Video-Avatar-1.5 \
    --local-dir /root/autodl-tmp/weights/LongCat-Video-Avatar-1.5

ln -sf /root/autodl-tmp/weights/LongCat-Video-Avatar-1.5 \
    /root/lip-sync/LongCat-Video/weights/LongCat-Video-Avatar-1.5

echo "=== 部署推理脚本 ==="
# 上传服务器端推理脚本
# infer_avatar.py 由本地 deploy_to_cloud.sh 部署

echo "✅ 云 GPU 环境初始化完成"
```

### 9.1.3 部署推理脚本

```bash
# scripts/deploy_to_cloud.sh
#!/bin/bash
CONFIG=${1:-config/local.yaml}

# 读取配置
HOST=$(yq e '.remote.ssh.host' $CONFIG)
PORT=$(yq e '.remote.ssh.port' $CONFIG)
REMOTE_DIR=$(yq e '.remote.ssh.remote_work_dir' $CONFIG)

# 上传推理脚本
scp -P $PORT src/remote/server/infer_avatar.py \
    root@$HOST:$REMOTE_DIR/server/

echo "✅ 推理脚本已部署"
```

### 9.2.3 成本估算

| 文件上传 | ~10 秒 | 免费 |
| LongCat 推理（480P INT8） | ~2~5 分钟 | ~¥0.10~0.25 |
| 文件下载 | ~5 秒 | 免费 |

## 9.3 常见问题排查

### SSH 连接问题

```bash
# 测试连接
ssh -v -i ~/.ssh/autodl root@<host> -p <port>

# 检查 SSH 密钥权限
chmod 600 ~/.ssh/autodl

# AutoDL 控制台检查
# 1. 实例是否开机
# 2. SSH 密钥是否正确绑定
# 3. 端口是否正确（不是默认 22）
```

### GPU 相关问题

```bash
# 检查 GPU 状态（远程）
ssh autodl-longcat "nvidia-smi"

# 检查 CUDA 版本
ssh autodl-longcat "nvcc --version"

# 检查 PyTorch CUDA
ssh autodl-longcat "python -c 'import torch; print(torch.cuda.is_available())'"

# OOM 时：降低分辨率
# --resolution 480P 代替 720P
# 或增加 num_gpus 到 2
```

### 推理质量问题

| 问题 | 可能原因 | 解决方法 |
|------|---------|---------|
| 唇形不同步 | Audio CFG 太低 | 调高 `--audio_cfg`（推荐 3~5） |
| 人物动作重复 | ref_img_index 不合适 | 设为 30 或更大值 |
| 画面闪烁 | mask_frame_range 太小 | 增大到 5~8 |
| 背景畸变 | 图片预处理不当 | 检查人脸裁剪和背景填充 |
| 视频太短 | 音频太短 | 增加文案或放慢语速 |
| 生成失败 | 显存不足 | 使用 INT8 + 480P |
