# 04 — 环境搭建指南

## 4.1 部署方案选择

根据 TTS 位置和云 GPU 接入方式，有 6 种组合方案：

| 方案 | TTS 位置 | 云接入 | 说明 |
|------|---------|-------|------|
| **方案 A（推荐）** | 本地 Mac | SSH | 开发调试首选，本文将详细介绍此方案 |
| **方案 B** | 本地 Mac | HTTP API | 使用 Modal/Replicate 等 Serverless |
| **方案 C** | 云端 GPU | SSH | 全量在云上运行，本地仅控制 |
| **方案 D** | 云端 GPU | HTTP API | 全云化 + API 服务化 |

> 本文以 **方案 A** 为例，其他方案在对应小节标注差异。

---

## 4.2 本地环境（方案 A/B 均需）

### 4.2.1 基础环境

```bash
# 创建 Python 3.10 环境
conda create -n lip-sync python=3.10 -y
conda activate lip-sync

# 基础 Python 包
pip install pyyaml requests tqdm colorama
```

### 4.2.2 安装 CosyVoice TTS

仅方案 A 和 B（TTS 在本地）需要：

```bash
git clone https://github.com/FunAudioLLM/CosyVoice.git --branch main
cd CosyVoice
pip install -r requirements.txt
pip install -e .

# 下载模型
pip install "huggingface_hub[cli]"
huggingface-cli download FunAudioLLM/CosyVoice-300M-SFT \
    --local-dir ./pretrained_models/CosyVoice-300M-SFT
cd ..
```

> **国内网络替代**（ModelScope 镜像）：
> ```python
> from modelscope import snapshot_download
> snapshot_download('iic/CosyVoice-300M-SFT',
>     local_dir='./pretrained_models/CosyVoice-300M-SFT')
> ```

### 4.2.3 安装 SSProvider 依赖

仅方案 A（SSH 接入）需要：

```bash
pip install paramiko
```

### 4.2.4 安装 HTTPProvider 依赖

仅方案 B（HTTP API 接入）需要：

```bash
pip install httpx
```

### 4.2.5 其他通用依赖

```bash
# 音频处理
conda install -c conda-forge librosa ffmpeg -y
pip install soundfile pydub

# 图片处理
pip install opencv-python pillow scikit-image

# 字幕
pip install pysrt
```

## 4.3 云 GPU 环境（所有方案均需）

### 4.3.1 通用云 GPU 依赖

无论使用哪家厂商，云 GPU 上都需要安装：

```bash
# 确认 GPU
nvidia-smi

# 创建环境
conda create -n longcat python=3.10 -y
conda activate longcat

# 安装 PyTorch + CUDA
pip install torch==2.6.0+cu124 torchvision==0.21.0+cu124 torchaudio==2.6.0 \
    --index-url https://download.pytorch.org/whl/cu124

# 安装 FlashAttention
pip install ninja psutil packaging
pip install flash_attn==2.7.4.post1

# 音频处理
conda install -c conda-forge librosa -y
conda install -c conda-forge ffmpeg -y

# 其他
pip install diffusers safetensors onnx onnxruntime
pip install "huggingface_hub[cli]"
pip install tqdm pyyaml opencv-python pillow
```

### 4.3.2 方案 A/C 额外依赖（SSH 模式）

SSH 模式只需上述基础依赖 + 推理脚本：

```bash
# 克隆 LongCat 推理代码
git clone --single-branch --branch main \
    https://github.com/meituan-longcat/LongCat-Video.git \
    /root/lip-sync/LongCat-Video

cd /root/lip-sync/LongCat-Video
pip install -r requirements_avatar.txt

# 上传推理脚本（从本地执行）
scp -P <port> src/remote/server/infer_avatar.py \
    root@<host>:/root/lip-sync/server/
```

### 4.3.3 方案 B/D 额外依赖（HTTP 模式）

HTTP 模式需要额外安装 API 服务：

```bash
# 安装 FastAPI + Uvicorn
pip install fastapi uvicorn python-multipart

# 上传 API 服务脚本（从本地执行）
scp -P <port> src/remote/server/api_server.py \
    src/remote/server/infer_avatar.py \
    root@<host>:/root/lip-sync/server/

# 在云 GPU 上启动 API 服务（后台运行）
nohup python /root/lip-sync/server/api_server.py \
    --port 8000 \
    --weights /root/autodl-tmp/weights/LongCat-Video-Avatar-1.5 \
    > /root/lip-sync/server.log 2>&1 &
```

### 4.3.4 下载模型（通用）

```bash
# 方式一：HuggingFace
huggingface-cli download meituan-longcat/LongCat-Video-Avatar-1.5 \
    --local-dir /root/autodl-tmp/weights/LongCat-Video-Avatar-1.5

# 方式二：ModelScope（国内更快）
pip install modelscope
python -c "
from modelscope import snapshot_download
snapshot_download('meituan-longcat/LongCat-Video-Avatar-1.5',
    local_dir='/root/autodl-tmp/weights/LongCat-Video-Avatar-1.5')
"
```

### 4.3.5 方案 C/D 额外步骤：云端安装 TTS

如果选择 TTS 部署在云端：

```bash
# 在云 GPU 上安装 CosyVoice
ssh root@<host> -p <port> "
    cd /root/lip-sync
    git clone https://github.com/FunAudioLLM/CosyVoice.git
    cd CosyVoice
    pip install -r requirements.txt
    pip install -e .
    
    # 下载模型
    pip install huggingface_hub
    huggingface-cli download FunAudioLLM/CosyVoice-300M-SFT \
        --local-dir ./pretrained_models/CosyVoice-300M-SFT
"
```

## 4.4 SSH 密钥配置（方案 A/C）

```bash
# 生成密钥
ssh-keygen -t ed25519 -f ~/.ssh/cloud_gpu -N ""

# 添加到云 GPU（以 AutoDL 为例）
cat ~/.ssh/cloud_gpu.pub
# → 复制公钥，粘贴到 AutoDL 控制台 → SSH 密钥

# 配置 ~/.ssh/config
cat >> ~/.ssh/config << 'SSHEOF'
Host auto-gpu
    HostName <your-instance-ip>
    Port <port>
    User root
    IdentityFile ~/.ssh/cloud_gpu
    ServerAliveInterval 30
    ServerAliveCountMax 5
SSHEOF

# 测试连接
ssh auto-gpu
```

## 4.5 HTTP API 服务端部署（方案 B/D）

如果选择 HTTP 模式，需要在云 GPU 上部署 API 服务：

### API 服务结构

```bash
/root/lip-sync/server/
├── api_server.py       # FastAPI 服务入口
├── infer_avatar.py     # LongCat 推理逻辑
└── api_server.log      # 运行日志
```

### 启动 API 服务

```bash
# 手动启动（调试用）
python /root/lip-sync/server/api_server.py \
    --port 8000 \
    --weights /root/autodl-tmp/weights/LongCat-Video-Avatar-1.5

# 后台运行（生产用）
nohup python /root/lip-sync/server/api_server.py \
    --port 8000 \
    --weights /root/autodl-tmp/weights/LongCat-Video-Avatar-1.5 \
    > /root/lip-sync/server.log 2>&1 &
```

### API 端点

| 端点 | 方法 | 说明 |
|------|------|------|
| `POST /infer` | multipart | 上传文件+提交推理，返回 task_id |
| `GET /status/{task_id}` | JSON | 查询推理状态 |
| `GET /download/{task_id}` | 文件流 | 下载结果视频 |
| `GET /health` | JSON | 健康检查（含 GPU 状态） |

## 4.6 配置项目

```bash
# 复制配置模板
cp config/default.yaml config/local.yaml

# 根据方案选择编辑配置
vim config/local.yaml
```

**不同方案的配置示例：**

### 方案 A（本地 TTS + SSH）

```yaml
tts:
  engine: "cosyvoice"
  run_on: "local"            # TTS 在本地
  model_dir: "pretrained_models/CosyVoice-300M-SFT"
  device: "cpu"

provider:
  type: "ssh"                # SSH 接入云 GPU
  ssh:
    host: "your-instance-ip"
    port: 12345
    username: "root"
    key_filename: "~/.ssh/cloud_gpu"
    remote_work_dir: "/root/lip-sync"
    remote_weights_dir: "/root/weights/LongCat-Video-Avatar-1.5"
```

### 方案 B（本地 TTS + HTTP）

```yaml
tts:
  engine: "cosyvoice"
  run_on: "local"
  model_dir: "pretrained_models/CosyVoice-300M-SFT"
  device: "cpu"

provider:
  type: "http"               # HTTP API 接入
  http:
    api_base_url: "https://api.modal.com/lip-sync"
    api_key: "sk-xxxxxxxxxxxx"
```

### 方案 C（云端 TTS + SSH）

```yaml
tts:
  engine: "cosyvoice"
  run_on: "cloud"            # TTS 在云端执行
  
provider:
  type: "ssh"
  ssh:
    host: "your-instance-ip"
    port: 12345
    username: "root"
    key_filename: "~/.ssh/cloud_gpu"
```
